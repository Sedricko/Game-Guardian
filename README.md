# Tinker

Editor de memória para Android, aberto, focado em jogos single-player/offline.
Inspirado no GameGuardian, com interface mais simples e recursos novos
(pointer scanner, IL2CPP, tabelas de cheat compartilháveis).

Análise do GameGuardian 101.4 que serviu de base: [docs/analise](docs/analise/README.md).
